# Estrutura principal

header: cabeçalho da página ou seção
nav: área de navegação (menus)
main: conteúdo principal (um por página)
section: separa blocos de conteúdo
article: conteúdo independente (card, post)
aside: conteúdo lateral
footer: rodapé
div: container genérico 
span: container inline


# Textos

h1-h6: títulos hierarquia textos vão diminuindo
p: parágrafo
strong: destaque importante negrito 
em: ênfase itálico 
br: quebra de linha
hr: linha divisória

# Imagens

img: adiciona imagem
src: caminho da imagem
alt: descrição (acessibilidade)

video: adiciona vídeo
audio: adiciona áudio
source: define fonte de mídia

picture: imagem responsiva

# Listas

ul: lista não ordenada
ol: lista ordenada
li: item da lista
dl: lista de definição
dt: termo
dd: descrição

# Formularios

form: formulário
input: campo de entrada
type="text": texto
type="email": email
type="password": senha
type="number": número
type="file": arquivo
type="checkbox": seleção múltipla
type="radio": seleção única

textarea: texto longo
select: lista de opções
option: item da lista
button: botão

label: descrição do campo
for: conecta label ao input
name: nome do campo (backend)
required: campo obrigatório

# Head/Meta

meta charset="UTF-8": define encoding
meta name="viewport": responsividade
meta name="description": SEO
link: importa CSS
script: importa JS
defer: carrega JS sem travar página
